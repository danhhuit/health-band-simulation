# Dashboard

Dashboard MVP cần hiển thị:

- Nhịp tim theo BPM.
- SpO2 theo phần trăm.
- Tổng số bước.
- Trạng thái té ngã.
- Mức pin.
- Trạng thái kết nối và thời gian bản tin cuối.
- Danh sách cảnh báo gần nhất.

Ưu tiên giao diện dễ đọc và chứng minh dữ liệu thời gian thực; chưa cần tối ưu cho điện thoại trong giai đoạn đầu.
