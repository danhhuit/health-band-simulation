# Firmware Wokwi

Thư mục này sẽ chứa:

- `sketch.ino`: chương trình ESP32.
- `diagram.json`: sơ đồ linh kiện ảo Wokwi.
- `libraries.txt`: danh sách thư viện.

Mốc đầu tiên:

1. Tạo dự án ESP32 trên Wokwi.
2. Thêm nút `STEP` và `FALL`.
3. Dùng `INPUT_PULLUP` và chống dội nút.
4. In trạng thái lên Serial Monitor.
5. Chạy liên tục 3 phút không treo và không phát sinh nhấn giả.
